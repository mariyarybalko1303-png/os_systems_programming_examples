# 🖥️ Веб-реконструкції архітектури операційних систем
### Наочні інтерактивні моделі для курсу «Операційні системи та системне програмування»

Цей репозиторій містить автономні браузерні моделі (інтерактивні симуляції) знакових операційних систем, які демонструють ключові етапи еволюції віконних підсистем, моделей пам'яті, керування процесами та файловими структурами.

Кожна симуляція є самодостатнім веб-додатком (Single File HTML/CSS/JS), який запускається в один клік у будь-якому сучасному браузері без потреби встановлювати віртуальні машини чи емулятори.

---

## 📂 Склад репозиторію та огляд моделей

### 1. `windows_longhorn_build_4074_simulation.html`
**Модель:** Windows Longhorn Build 4074 (Milestone 7 / WinHEC 2004)  
**Архітектурна епоха:** Перехідний етап між Windows XP та Windows Vista (травень 2004 року).

* **Ключові візуалізовані компоненти:**
  * **Тема інтерфейсу Slate / Jade:** Ранні експерименти з композитним віконним менеджером (DWM), напівпрозорими заголовками та апаратним прискоренням графіки.
  * **Sidebar (Бічна панель):** Концепція фонового розміщення активних плиток-віджетів (годинник, моніторинг ресурсів, слайд-шоу).
  * **Концепція WinFS (Windows Future Storage):** Спроба замінити ієрархічні папки динамічними реляційними сховищами метаданих на базі рушія SQL Server.
* **Навчально-інженерна цінність для курсу:**
  * **Кейс «Великого перезавантаження» (Development Reset):** Наочна демонстрація того, що стається, коли амбіції архітекторів (впровадження керованого коду .NET у простір ядра, підсистеми Avalon/WPF та Indigo/WCF) випереджають можливості апаратного забезпечення свого часу.
  * Розуміння причин, чому кодову базу Longhorn довелося зупинити у серпні 2004 року та перезбирати платформу з чистого аркуша на базі стабільного ядра Windows Server 2003 SP1.

### 2. `retro_mac_os_7_5_simulation.html`
**Модель:** Apple System 7.5 (Classic Mac OS)  
**Архітектурна епоха:** Золотий вік класичної платформи Macintosh (1994–1997 роки).

* **Ключові візуалізовані компоненти:**
  * **Графічна підсистема QuickDraw та Finder:** Класичне просторове керування файлами (Spatial Finder), віконна модель із характерним смугастим заголовком та кнопками масштабування/закриття.
  * **Панель керування Control Strip:** Системний висувний рядок віджетів для швидкого доступу до налаштувань звуку, живлення та монітора.
  * **Меню Apple («Яблучко») та Desk Accessories (DA):** Робота з ранніми вбудованими мікрододатками (калькулятор, блокнот, панелі налаштувань).
* **Навчально-інженерна цінність для курсу:**
  * **Кооперативна багатозадачність проти витісняльної:** Студенти бачать, як працювала ОС, де процес сам мав віддавати квант процесорного часу системі (через функцію `WaitNextEvent`), і чому зависання однієї програми призводило до збою всієї системи.
  * **Спільний адресний простір і відсутність захисту пам'яті:** Практичне пояснення того, чому Classic Mac OS не мала апаратного розмежування Ring 0 / Ring 3 для кожного процесу, що врешті викликало кризу проєкту Copland та перехід Apple на ядро Mach/BSD у Mac OS X.

## 📊 Порівняльна таблиця архітектурних характеристик

| Архітектурний параметр | Apple System 7.5 (1994) | Windows Longhorn Build 4074 (2004) | Сучасні стандарти (Linux 6.x / Win 11) |
| :--- | :--- | :--- | :--- |
| **Модель багатозадачності** | Кооперативна (`WaitNextEvent`) | Витісняльна (Preemptive Scheduling) | Витісняльна з динамічними пріоритетами |
| **Захист пам'яті** | Спільний адресний простір | Апаратні кільця (Ring 0 / Ring 3) | Повна ізоляція, ASLR, NX-біт, cgroups v2 |
| **Графічний стек** | QuickDraw (растровий 2D-рушій) | Avalon / DWM (ранній DirectX) | Wayland / Desktop Window Manager |
| **Файлова підсистема** | HFS (ієрархічні ресурси та дані) | Експериментальний реляційний WinFS | Журнальовані ext4/btrfs, NTFS, ZFS |
| **Стійкість до відмов** | Критичний системний збій | Перезапуск explorer.exe / ядра | Ізоляція в пісочницях, systemd-coredump |

## 🚀 Як запускати моделі

### Спосіб 1: Локальний запуск (найшвидший)
1. Склонуйте репозиторій або завантажте його як ZIP-архів:
   ```bash
   git clone https://github.com/<username>/os_systems_programming_examples.git
   cd os_systems_programming_examples
   ```
2. Відкрийте у будь-якому браузері (Chrome, Firefox, Safari, Edge) потрібний файл:
   * `windows_longhorn_build_4074_simulation.html`
   * `retro_mac_os_7_5_simulation.html`

### Спосіб 2: Онлайн через GitHub Pages
Якщо в налаштуваннях репозиторію увімкнено **Settings → Pages** (гілка `main`, root `/`):
* Симуляція Longhorn 4074: `https://<username>.github.io/os_systems_programming_examples/windows_longhorn_build_4074_simulation.html`
* Симуляція Mac OS 7.5: `https://<username>.github.io/os_systems_programming_examples/retro_mac_os_7_5_simulation.html`

## 🎯 Навчальні цілі практичного заняття
1. **Порівняльний аналіз інтерфейсних парадигм:** від класичного меню 90-х років (System 7.5) до концепції бічних панелей і векторної графіки (Longhorn).
2. **Дослідження поведінки віконних менеджерів:** взаємодія вікон, фокусування, стек глибини (`z-index`) та реакція на події миші.
3. **Розуміння архітектурних компромісів:** зіставлення теоретичних можливостей операційної системи та реальних обмежень доступного заліза й моделі пам'яті.
